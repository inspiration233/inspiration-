# Excel 工具

本地桌面工作台，文件在本机处理。合并、拆分、对照回填可以单独使用，也可以组合成“总表拆分 → 收集反馈 → 更新总表”的流程。

## 启动

日常使用时，Windows 双击根目录的 **`启动工具.cmd`** 即可，**不需要每次运行 `npm ci`**。启动脚本会检查 Electron 和 Python 依赖；缺失时给出具体提示。

`npm ci` 仅在首次安装或更新依赖时执行。安装前请先退出工具窗口，等待程序结束，再运行以下命令：

```powershell
python -m pip install -r requirements.txt
cd app
npm ci
npm start
```

如果 `npm ci` 报 `EBUSY`（例如无法删除 `electron/dist/icudtl.dat`），说明文件仍被运行中的程序占用。请先退出工具窗口，确认程序已结束，再重试安装。

如有多套 Python，可设置 `TOOLBOX_PYTHON` 为已安装依赖的解释器完整路径。启动脚本优先检查该设置，其次检查项目 `.venv`、`venv` 和系统 `python`。本次交付为可直接运行的项目版本，尚未制作免安装发行包。

## 操作

1. 选“合并”“拆分”或“对照回填”，加入文件。
2. 在原表预览中确认工作表、表头和数据区域。既可输入 `A4:G4` 这样的坐标，也可点击“在表上框选”，依次选两个角。
3. 按本次用途点选字段，预览结果；需要确认的冲突集中显示在这里。
4. 确认后导出新文件。输入文件不覆盖，已存在的结果文件也不会被覆盖。

**合并**：可以把记录拼到总表、按同名工作表汇总，或把各张工作表独立装入同一文件。默认保留内容、编号和原表样式；手动字段对应可处理改名或换列。需要完整保留独立布局时选“装入同一文件”。

字段匹配会忽略全角/半角、字母大小写及重复空白差异，显示仍保留原文；单层与多层表头只在末级字段能够唯一对应时合并，不会把“计划/数量”和“实际/数量”混为一列。同一文件中的其他工作表也可手动对应；仅调整数据范围会保留已有字段对应。外部调整列顺序后，已设对应会按字段身份自动迁移；不能唯一找到原字段时提示重新核对，避免沿用旧列号写错内容。

各来源的单位抬头、前置说明不同，或前置区/表头含来源自己的公式时，会自动在同一工作表保留各自表块，并在预览说明原因。每块保持原列顺序和计算参数，不默认添加单位列。共同且不含公式的前置区继续共用一份表头。一个工作表只能共用列宽，来源列宽不同会采用版式参考表的列宽并提示。

自动识别的范围保留识别不确定提示；手动应用范围才视为确认。合并预览会重新读取自动范围，避免添加文件后外部增删记录导致旧范围遗漏；手动选择的范围则按用户选择保留。

**拆分**：点选任意分组字段，按每行或每列拆分；也可用固定单元格、工作表名命名。筛选支持指定内容、月份和起止区间。“输出字段”可以只保留部分月份列。空白分组默认单独保留，也可选择跟随上一条非空归属；原格中的空白仍保留。合并单元格、分组小计等涉及语义变化时，会先要求在预览中确认。

**对照回填**：选择一份底表及反馈文件，在底表上指定“对应同一条记录”“允许回填”“调整后标红”三组字段。可组合多个字段匹配，无需固定编号列或单位字典。重复、冲突、新增记录需在预览中处理；未收到反馈的记录保留当前内容，并列在“本次未反馈”清单中。

计划调整用红字标记；只勾选计划字段作标红依据，完成数或状态等正常反馈可以只回填。需要持续与年初计划比较时，在“另选一份原始版本”中选择年初表；工具不会修改这份原表。改回原计划值后，字体颜色恢复为基线颜色。未选原始版本时，本次与当前底表比较。

回填可勾选“同时导出筛选后的结果”，例如生成全年更新表和当月表。区间筛选按所选起止字段覆盖目标月份判断；全年表不会因每月分发而重复增加记录。没有符合条件的记录时，预览会说明本次只输出完整表。

**复用方案**：保存表头结构、范围、字段用途、筛选和对应关系；换文件后按完整表头重新对应。表头移动或列重排可以复用，重复或无法唯一匹配的字段会暂停并请用户补选。方案不包含固定业务统计逻辑。

## 保真边界

- 拆分、回填与独立成页原生路径支持 `.xlsx`。合并兼容 `.xls`、`.csv`，但这些格式无法完整携带 XLSX 样式属性，界面会提示先另存为 `.xlsx`。
- 保留并重定位适用的标题、合并区域、字体/填充/边框、数字格式、行高列宽、冻结、打印设置、公式、数据验证、条件格式、命名区域和表对象。
- 横向记录拼成一张总表时会转为纵向记录，预览明确提示；横向拆分和回填继续保持原方向。
- 默认尽量保留原表外观。扩展样式（xl/styles.xml）、工作簿扩展（xl/workbook.xml）及其他未识别的 XML 扩展信息均只作兼容提示，允许继续导出，无需另外开启宽松模式。提示在预览和完成页均可查看；对应的附加信息或功能可能未保留，但不会仅因扩展名称不在已知列表中而阻止导出。
- 公式保留为公式，交给 Excel/WPS 打开后重算。无法可靠重定位且会影响计算的公式、数据合并区截断、对应关系不明确等问题继续阻止导出。
- 合并时图表/图形或打印机专属设置可能未保留，会提示后继续处理单元格内容；普通纸张、边距等设置仍尽量保留。拆分/回填仍会拦截不能可靠处理的图表、数据透视或外部依赖。损坏文件、宏及复杂数据对象仍有支持边界，预览会说明具体原因。
- 使用自定义颜色或字体主题时，普通拼接提示部分外观可能变化并继续导出；独立成页可以转换普通单元格的主题颜色/字体。自定义表样式或主题与表样式的组合也改为提示，不再仅因样式问题阻止导出。
- 跨文件复制整行样式时会在目标工作簿重新登记字体、填充、边框和数字格式；工作表窗口引用也会重新对应。导出前检查 ZIP/XML、内部关系和样式/窗口引用，防止发布结构损坏的结果。这项检查不限制未知扩展功能，扩展兼容性仍按提示处理。
- 原生模式会在内存中装载工作簿，当前预览和测试以日常业务表为主。大文件的耗时和内存占用取决于规模与复杂度。真实 Excel/WPS 的计算、打印和交互仍需实机核对。

## 验证

本次交付验证：**431 项自动化测试通过**；真实 Electron 工作台验收通过，包含三模式预览与导出、方案换表复用、重名阻断、界面确认新增、未反馈明细查看，以及带扩展样式和 workbook.xml 扩展文件的提示、实际导出和输出值/公式回读。本轮新增核对默认字段规范化、多层表头、来源抬头与公式、自动范围更新和外部换列后的映射身份；界面实际验证同簿不同页映射、调整数据范围后保留映射、自动识别提示、六列输出，以及外部换列后的直接预览/导出、重新打开页面迁移映射、无法唯一恢复时重新确认后继续。v3 夹具自检为 **107 通过 / 0 失败 / 41 跳过 / 22 提醒**，其中跳过和提醒不计作产品通过。

针对“导出文件打不开”，新增整行样式、窗口引用及损坏输出不发布等 17 项回归。使用带高编号行样式和多个源窗口的合成表，实际导出自动安排、一张总表、同名表分别汇总、装入同一文件四种结果；在独立隐藏实例中，Microsoft Excel 16.0 与 WPS 12.0 均 4/4 正常只读打开。Excel 对修复前的两类坏包拒绝打开，修复后可打开；WPS 对这些修复前坏包也能容忍，因此该验证不代表已复现用户保密文件的所有兼容问题。未接触用户业务表格或正在使用的办公软件实例。

```powershell

python 测试集/泛用性验收_v3/自检.py
cd app

```

`tests/test_v3_product.py` 把真实 v3 文件交给产品引擎，核对 W1/W3 原生拆分、W2 月份列筛选、W1 全年与当月输出、W3 进度回填、W6 跨月筛选、C32/C33/C35/C36/C37 反馈边界和 RT42 往返一致性，并覆盖全部 91 个 XLSX 的读取预览。其他测试覆盖字段重排、公式/规则重定位、冲突、新增、缺失、取消、保真边界和输入文件保护。

界面测试启动隔离设置的 Electron 实例，实际调用 Python 引擎执行三种模式、保存和复用方案及导出，结果和截图保存在 `tmp/workbench-ui-*`。

`测试集/泛用性验收_v3/自检.py` 检查的是测试夹具自身。它的通过数不能替代产品测试，也不能证明所有歧义已经自动解决；W4/W5 仍属于结构案例。

## 实现

- 界面：Electron + HTML/CSS/JavaScript。
- 引擎：Python + openpyxl，沿用现有原生 Excel 读写。
- 方案保存在本机应用数据中；导出回填结果同时生成 `.changes.json` 变更清单。
- 更完整的需求沿革见 `需求说明.md` 与 `UI设计说明.md`，以文末的通用工作台约定为准。
