# 测试集说明

本测试集刻意做得"脏"：列序不同、列名带空格、多余/缺失列、空行、合计行、混合日期格式、GBK 编码、老格式 xls、损坏文件等，全部来自真实办公场景的常见坑。**不要手工清理这些文件，脏点就是测试点。**

重新生成 / 调整规模：

```bash
python 生成测试集.py               # 默认大规模文件各 10 万行
python 生成测试集.py --rows 5000   # 小规模快速生成
python 生成测试集.py --skip-large  # 跳过大规模文件
```

## 边缘情况

| 文件 | 场景 | 预期行为 |
|------|------|----------|
| 表头不在第一行.xlsx | 第1行是合并了 A1:F1 的标题，真表头在第2行 | 表头自动探测定位到第2行，标题不进总表，正常合并（场景E能力的最简变体） |
| 双行表头.xlsx | 单文件双行表头 | **输出保留两行表头结构**，同场景E规则 |
| 样式丰富.xlsx | 填充色/字体/千分位数字格式/列宽/冻结首行 | "保留原样式"模式下尽量还原；"统一样式"模式下输出干净数据 |
| 日期格式混乱.xlsx | 真日期、`2026/10/2`、`10月4日`、`2026.10.5`、序列号 46552 混杂 | 数据原样透传不丢失、不自作主张转换 |
| 重名列与无名列.xlsx | 平铺表头里**两个"金额"列**；E列无表头但有数据；地址单元格含 Alt+Enter 换行；16位数字单号（源头已损）；身份证号为文本 | 重名列内部键加 `(1)/(2)`；无表头列有数据则命名`未命名n`保留；换行原样保留；损坏的长数字透传（救不回）；**工具输出侧遇 >15 位数字必须转文本防损**（openpyxl `%.16g` 实测坑） |
| 隐藏Sheet.xlsx | 可见"销售"页 + 隐藏"配置"页（模板下拉选项，真实模板常有） | 隐藏 Sheet 默认跳过并在报告列出；设置可改为包含 |

## 已固化的行为约定（对应需求说明.md V1.1，改动需两边同步）

1. **列名规范化**（匹配时使用，输出保留原始列名）：去首尾空格、折叠连续空格、全角→半角、英文统一小写；严格/宽容两种模式都启用（已确认"姓名 "≡"姓名"）。
2. **表头行自动探测**为默认行为，界面保留"手动指定行号"兜底；报告列出每个文件判定出的表头行号。
3. **表头结构保留（V1.2 定案）**：输出表头按"表头模板文件"（默认文件列表第一个，界面可指定）**原样还原**行数与合并单元格。展平只作内部对齐键、用户不可见：跨列合并+子级→`父/子`复合键；跨行合并→单列名；末行横向合并无子级→`(1)/(2)` 内部键（输出仍是一格）。单行表头可与多行表头互相对齐；多出的列追加最右端、表头纵向合并跨满表头行数；缺的列数据区留空。标题/制表行不进总表（报告记录；"以第一个文件标题为总表标题"开关默认关）。**纵向合并越界**（延伸进数据区）：内容信号优先，表头区域不扩展，被覆盖数据格按空值透传并报告提示。转置表（表头在左侧第一列）V1 不支持。
4. **合计/小计行剔除**：默认开启可关闭；只检查数据行的**前两列**，文本等于或以关键词（合计/小计/总计/汇总/累计，可增删）结尾即剔除；剔除计数进报告。
5. **合计行之外不自动剔除任何数据**（如空行跳过，但不删内容行）。
6. **CSV 无 Sheet**：模式 B/D 中视为单 Sheet 文件，Sheet 名 = 文件名（去扩展名）；模式 C 不适用 CSV；CSV 前导空行跳过。
7. **语义同义列**（客户姓名~客户名称）**已砍除**（需求说明 V1.7 需求方决策）：部门D 在宽容模式下产生新列是**最终预期行为**，不是 bug，不要当成缺陷上报。
8. **数据区合并还原**：保留样式模式或工作簿模式下，数据区的合并单元格按行号映射翻译到输出坐标还原（跨分页或中间跳行的合并丢弃）；统一样式模式不做（干净数据原则）。列宽在这两种模式下从模板复制。

## 其他已知但未覆盖的点

- **公式**：openpyxl 生成的公式没有缓存值，真实 Excel 保存的文件才有。工具读值依赖缓存值，因此测试集未放公式文件；如有真实含公式的报表，建议后续拿真实文件补测。
- **密码保护文件**：无法用脚本生成，读取必然失败，错误路径已被"损坏文件.xlsx"覆盖。
